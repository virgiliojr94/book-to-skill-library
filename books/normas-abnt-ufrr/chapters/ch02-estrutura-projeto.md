# Capítulo 2: Documentos e Estrutura do Projeto de Pesquisa

## Core Idea
O projeto de pesquisa da UFRR segue a ABNT NBR 15287 e é composto de elementos pré-textuais, textuais e pós-textuais com obrigatoriedade específica.

## Estrutura Completa do Projeto de Pesquisa

### Elementos Pré-textuais
| Elemento | Obrigatoriedade |
|---|---|
| Capa | **Obrigatório** |
| Folha de rosto | **Obrigatório** |
| Lista de ilustrações | Opcional |
| Lista de tabelas | Opcional |
| Lista de abreviaturas | Opcional |
| Lista de siglas | Opcional |
| Lista de símbolos | Opcional |
| Sumário | **Obrigatório** |

### Elementos Textuais (conteúdo do projeto)
| Elemento | Obrigatoriedade | O que deve conter |
|---|---|---|
| Apresentação | **Obrigatório** | Expõe o tema e linhas gerais da pesquisa; problema e hipótese podem estar aqui |
| Problema | **Obrigatório** | Enfoque central; pode ser formulado como pergunta |
| Hipóteses | Opcional | Afirmações a serem testadas por análise de dados empíricos |
| Objetivo | **Obrigatório** | Metas do trabalho; verbo no **infinitivo** (Analisar, Desenvolver, Propor) |
| Justificativa | **Obrigatório** | Relevância, viabilidade, caráter inovador ou original |
| Referencial teórico | **Obrigatório** | Base científica/filosófica; definição dos conceitos norteadores |
| Metodologia | **Obrigatório** | Modalidade (campo, bibliográfica, experimental), coleta, análise, amostragem |
| Recursos | Condicional | Orçamento detalhado: materiais, humanos, financeiros |
| Cronograma | **Obrigatório** | Fases até entrega à banca (dias, semanas ou meses) |

### Elementos Pós-textuais
| Elemento | Obrigatoriedade |
|---|---|
| Referências | **Obrigatório** |
| Glossário | Opcional |
| Apêndices | Opcional (material produzido pelo próprio autor) |
| Anexos | Opcional (material de terceiros) |
| Índice | Opcional |

## Capa — O Que Deve Ter
1. Nome da instituição: UNIVERSIDADE FEDERAL DE RORAIMA
2. Centro/Programa: ex: PROGRAMA DE PÓS-GRADUAÇÃO EM COMPUTAÇÃO APLICADA — PPCA
3. Nome do(a) autor(a)
4. Título do trabalho
5. Subtítulo (se houver, precedido de dois pontos)
6. Local: BOA VISTA, RR
7. Ano: em algarismos arábicos

## Folha de Rosto — O Que Deve Ter
1. Nome do(a) autor(a)
2. Título e subtítulo
3. **Nota de natureza do trabalho** (alinhada no meio da mancha gráfica para margem direita, fonte 10):
   > "Projeto de pesquisa apresentado ao Programa de Pós-graduação em Computação Aplicada da Universidade Federal de Roraima como requisito para [finalidade], na linha de pesquisa [nome da linha]."
4. Nome do(a) orientador(a) com titulação abreviada (ver Quadro 1 do manual)
5. Nome do(a) coorientador(a) (se houver)
6. Local e ano

## Anti-patterns
- **Incluir ficha catalográfica no projeto**: ela vai apenas na versão final (dissertação/tese)
- **Incluir folha de aprovação no projeto**: idem
- **Objetivo sem verbo no infinitivo**: "O estudo visa a..." → "Analisar..."
- **Cronograma sem datas reais**: colocar prazos concretos, não aproximados

## Worked Example — Nota de Natureza
```
Projeto de pesquisa apresentado ao Programa de Pós-
graduação em Computação Aplicada (PPCA) da Universidade
Federal de Roraima (UFRR) como requisito para obtenção
do título de Mestre em Computação Aplicada, na linha de
pesquisa [nome da linha de pesquisa do PPCA].

Orientador: Prof. Dr. [Nome Sobrenome]
```
*(Fonte 10; alinhado à direita da mancha gráfica — metade direita da página)*

## Key Takeaways
1. Projeto ≠ versão final: sem ficha catalográfica, sem folha de aprovação
2. Verbos dos objetivos no infinitivo (analisar, propor, desenvolver, comparar, avaliar)
3. Metodologia deve justificar como os objetivos serão alcançados
4. Toda referência no texto deve aparecer na lista de referências
